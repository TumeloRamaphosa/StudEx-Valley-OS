# second-brain — Creative Output Layer

## What It Is
A suite of creative tools for AI agents to produce polished outputs: brand-consistent content, presentations, videos, and standard operating procedures.

## Tools Included

### Brand Voice Generator
- Trains on StudEx brand guidelines
- Generates copy in Tumelo's voice
- Consistent tone across all agent outputs
- Brand: Cream + Gold + Pink + Dark, South African pharma, 10-year anniversary

### PPTX Maker
- Python pptx library integration
- Template: StudEx branded slides
- Auto-populate from agent data
- Use case: Africa distribution proposal, partner pitch decks

### MCP Client
- Model Context Protocol integration
- Connect to 50+ external tools
- Already in Valley OS (src/lib/mcp.ts)
- Standard for agent tool use

### SOP Creator
- Generate standard operating procedures
- Auto-document agent workflows
- Compliance-ready format
- Use case: Government VM onboarding SOP, cold chain SOP

### Remotion Video
- React-based video generation
- Animated data visualizations
- Trade show presentation videos
- Use case: 10-year anniversary video, Africa expansion announcement

## Valley OS Integration
- All tools available via agent tool calls
- Brand voice = system prompt for all agents
- SOPs auto-generate on agent workflow creation

## Status
✅ Active — embedded in Valley OS agent system
